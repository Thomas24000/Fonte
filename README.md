# Fonte

Mémo de muscu : tes salles, tes séances, tes exercices et tes poids.

- Au lancement, l'app demande à quelle salle tu es. Chaque salle a ses propres séances et poids.
- Les boutons − / + ajustent un poids ; l'historique et la courbe de progression se mettent à jour.
- Pour les exos à la barre (20 kg), les disques à mettre de chaque côté sont affichés.

Les données sont enregistrées **dans le navigateur du téléphone** (rien n'est envoyé ailleurs).
Pense à faire de temps en temps « Exporter mes données » depuis l'écran des salles pour garder une sauvegarde.

## Installer sur le téléphone

Ouvre l'adresse GitHub Pages du repo, puis :
- iPhone (Safari) : Partager → Sur l'écran d'accueil
- Android (Chrome) : ⋮ → Ajouter à l'écran d'accueil
